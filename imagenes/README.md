# Evidencias fotográficas reales del laboratorio

Se recopilaron 30 capturas enviadas durante la práctica, organizadas en el paquete `CIS_Imagenes_Para_GitHub.zip`.

Para publicarlas: extraer el ZIP en Windows; entrar a esta carpeta `imagenes/` en GitHub; pulsar **Add file → Upload files**; seleccionar los archivos PNG extraídos; confirmar **Commit changes**. NO subir los running-config en capturas que contengan hashes.
